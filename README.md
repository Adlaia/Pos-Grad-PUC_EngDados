# Pos-Grad-PUC_EngDados

Projeto de MVP - Engenharia de Dados

Descrição dos arquivos aqui presentes:

mvp_drugconsumption_final.ipynb:
Exportação de um único notebook feito no Databricks contendo todo o trabalho, com códigos, resultados e textos. Porém, alguns comandos de SQL que não retornam resultado acabam não tendo indicação de execução correta nesse arquivo.

MVP Engenharia de Dados - Amanda de Laia da Fonseca.pdf:
Réplica exata do notebook completo, com prints de todas as células de código, com comprovação de execução e resultados. Também está organizado por índice, então talvez seja mais fácil de ser lido. Acredito que ambos os arquivos, de forma combinada, possam sanar eventuais dúvidas que surgirem.

drug_consumption.csv:
Base de dados, previamente convertida de .data como foi baixada do site, utilizada no presente trabalho.
